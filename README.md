# Журнал групи -> один PDF

Локальна веб-програма для перетворення ZIP-архіву журналів `.xlsx/.xlsm` в один PDF, готовий до друку та подальшого підписання КЕП/ЕЦП.

## Основні правила

- A4, альбомна орієнтація на кожній сторінці.
- Один чорний Unicode-шрифт. На Windows використовується встановлений Times New Roman; якщо його немає - Tinos / Liberation Serif / DejaVu Serif.
- Шрифт вбудовується у PDF засобами ReportLab.
- Вихідні Excel-файли ніколи не перезаписуються.
- Оцінки, написи, дати та теми не виправляються автоматично.
- Якщо Excel містить формулу/помилку без коректного результату, програма показує попередження до створення PDF.
- У вікні попередження можна: залишити як є; вручну вказати значення тільки для PDF; залишити клітинку порожньою тільки в PDF.
- Для оцінок при перенесенні дат на нову сторінку повторюються назва дисципліни, викладач і повний список студентів.
- Теми формуються окремою таблицею з повторенням шапки на новій сторінці; довгі теми переносяться всередині клітинки.
- Дисципліни сортуються за алфавітом.
- Усі журнали об'єднуються в один PDF.

## Windows - найпростіший запуск

1. Розпакуйте папку програми.
2. Двічі натисніть `START_WINDOWS.bat`.
3. Під час першого запуску встановляться Python-залежності.
4. Браузер відкриє `http://127.0.0.1:8000`.
5. Натисніть **Відкрити архів з журналами групи**.
6. Після перевірки натисніть **Завантажити журнал групи в PDF**.

Дані обробляються локально на комп'ютері через `127.0.0.1`; програма не відправляє журнали на зовнішній сервер.

## Ручний запуск

```bash
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

## Технічні обмеження першої версії

- Підтримуються `.xlsx` і `.xlsm` усередині ZIP.
- Старий бінарний `.xls` не підтримується.
- ZIP обмежено 200 МБ; розпаковані файли - 500 МБ сумарно.
- Код читає видимі/кешовані результати формул Excel. Якщо кешований результат відсутній або містить помилку, це стає попередженням для ручного рішення.

## Нове у v1.1
- Живий лічильник під час перевірки архіву: `Перевірено N з M файлів`.
- Живий лічильник під час формування PDF: `Оброблено N з M предметів`.
- Смуга прогресу та анімація «Excel-сторінки -> журнал -> PDF».
- Відображення назви предмета/файлу, який обробляється зараз.
- Необов'язкові легкі жарти під час очікування; їх можна вимкнути прапорцем.
- Версія програми показується у верхній частині інтерфейсу.
